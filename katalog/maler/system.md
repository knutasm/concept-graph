# Eksempelsystem

## Formål

Hvilke prosesser støtter systemet, og hvilke begreper oppstår og endres her? For de begrepene
skal `kilde` i begrepet peke på dette systemet.

## Særegenheter

Ting som gjør at systemets data avviker fra forretningsbegrepene, f.eks.
"oppretter kunderecord allerede ved tilbud", "sletter kansellerte ordrer".

## Kontakt

Rolle/team som kan svare på spørsmål om dataene.
